⚙ API key 设置

为什么需要你填 key：「生成 Verilog」这一步要调用 DeepSeek， 费用按调用量算。这个项目是开源的，作者不能把自己的 key 放进去 —— 那样谁用都是花作者的钱。

  1. 去 platform.deepseek.com 注册并创建一个 key
  2. 复制那串 sk- 开头的字符，粘到下面
  3. 点「保存」。key 只存在你自己的浏览器里，不会上传到任何地方
填好之后就能用「生成」功能了
probe — verilog-lab
