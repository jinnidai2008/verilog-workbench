# 部署与安全说明

> 这份文档说明：怎么把工作台给**别人**用，以及这样做之后安全边界在哪。
> 所有结论都是**实测**得出的，不是推测。

---

## 一、三种使用方式

| 方式 | 谁能访问 | 要口令吗 | 适合场景 |
|---|---|---|---|
| **本机**（`start.bat`） | 只有你自己的电脑 | 不要 | 日常自己用、答辩现场自己演示 |
| **局域网**（`start-lan.bat`） | 同一网络里的人 | **要** | 让杜老师在办公室自己点着看 |
| **公网**（云服务器 + `--host 0.0.0.0`） | 拿到链接的人 | **要** | 老师在校外也能看 |

**三种方式的区别只有"监听地址"和"要不要口令"**，其余完全一样。

---

## 二、怎么用

### 本机（和以前一样）
双击桌面 `Workbench`。没有任何变化，**不需要口令**。

### 🌐 公网给杜老师看 —— **双击 `start-public.bat`**（推荐）

这是实测跑通的方案，**不用买服务器、不用配路由器、不用注册账号**。

**用法**：
1. 双击 `start-public.bat`
2. 等 20~40 秒，窗口里会打印一条**完整的公网链接**：
   ```
   ==========================================================
     SEND THIS LINK TO YOUR TEACHER
   ==========================================================

   https://held-cheese-hide-finances.trycloudflare.com/workbench.html?token=O-gead-D1Bd7VRRh
   ```
3. **把这条链接整条发给杜老师**（微信粘贴就行）
4. 他点开就能用 —— **不需要装任何东西**

**原理**：用 Cloudflare 的免费快速隧道（`cloudflared`），
在你这台机器和 Cloudflare 之间建一条加密通道，给你一个临时的公网 HTTPS 地址。

**注意事项**：

| 事项 | 说明 |
|---|---|
| **窗口不能关** | 关了服务就停了，老师就打不开了 |
| **地址每次变** | 每次重启 `start-public.bat` 都会拿到新地址，要重新发 |
| **首次加载慢** | 隧道带宽有限，页面本体 10 MB + 背景视频 7 MB，**文字先出来，视频稍后**。让老师等几秒 |
| **不要公开发** | 链接里带口令，只发给要用的人 |
| **不保证长期可用** | Cloudflare 的免账号隧道**没有可用性承诺**，适合"看一下"，不适合长期挂着 |

### 局域网（备选）
双击 `start-lan.bat`。同一网络里的人用打印出来的局域网地址。

> ⚠️ **实测提醒**：你这台机器**没有可用的局域网地址**
> （网卡上只有 WSL 虚拟网卡 `172.30.x`、"没拿到地址"的 `169.254.x`、
> 以及运营商级 NAT 的公网地址 `117.64.x`）。
> 所以这个方式**在你这台机器上大概率用不了** —— 直接用公网方案。

### 云服务器（进阶）
需要有台云主机，还要在上面装 WSL + iverilog + verilator + yosys，比较折腾。
```bash
python server.py 8787 --host 0.0.0.0
```

## 二·补、为什么之前"别人打不开"

排查过程中实测踩到的三个坑，都修了：

| 现象 | 真正原因 | 修法 |
|---|---|---|
| 网址打不开 | **服务没在跑**（窗口关了） | 这个工具是"双击启动、关窗即停"，不是常驻网站 |
| 给了个 IP 但自己都打不开 | `local_ip()` 用"连 8.8.8.8 看默认网卡"这个常见技巧，**拿到的是出口公网地址**（`117.64.142.177`），不是局域网地址 | 改成只挑真正的私有网段，并**排除** `169.254.x`（没拿到地址）和 `172.30.x`（WSL）；挑不到就**明说"没检测到局域网地址"** |
| 公网地址给了别人，别人打不开 | 用的是 `localtunnel`，它有个**防钓鱼密码页**，要求访客输入**宿主机器的公网 IP** —— 访客不可能知道 | **换成 Cloudflare 隧道**，没有拦路页（实测验证过） |

## 三、加了哪些防护（实测结果）

### ① 访问口令（token）

**只有对外监听时才强制** —— 因为只绑 `127.0.0.1` 时外面根本连不进来，加口令纯属给自己添堵。

实测（`--host 0.0.0.0` 时）：

| 请求 | 结果 |
|---|---|
| `GET /workbench.html`（无 token） | **401** ✓ 返回一个"需要访问口令"的说明页 |
| `GET /workbench.html?token=错的` | **401** ✓ |
| `GET /workbench.html?token=对的` | **302** → 种 cookie，并**把 URL 里的 token 抹掉** |
| `GET /__projects`（无 cookie） | **401** ✓ |
| `GET /__whoami` | 200（故意放行，用于端口探测） |

**设计细节**：
- 口令存在 `access_token.txt`，**重启不变** —— 所以你只需要发一次链接
- 口令正确后**立刻 302 跳到一个不含 token 的干净地址** —— 避免口令留在地址栏、浏览历史、以及别人的截图里
- 支持三种传法：URL `?token=`、Cookie、请求头 `X-Workbench-Token`
- 想换口令：编辑 `access_token.txt`，或设环境变量 `DSH_WORKBENCH_TOKEN`

### ② 目录围栏

**所有能测的工程必须落在 `D:\steam\Documents\dsh` 这个目录树里。**

实测：
```
在 WORKSPACE 外面造一个完全合法的工程（project.json 校验通过）
然后让服务切过去：

  状态 403
  {"ok": false, "error": "这个目录不在允许的范围内：...\outside-proj
                          只允许 D:\steam\Documents\dsh 下面的工程。"}
```

**为什么必须有这道锁**：没有它，任何拿到网址的人都能把服务指向磁盘上任意位置，
再用 EDA 工具去读写那里的文件。

**实现要点**：用 `Path.resolve()` 之后再比，而不是比字符串前缀 —— 否则 `..\..\` 能骗过去。

## 四、**残余风险**（必须知道）

**这道防线是"防陌生人"，不是"防熟人"。**

我用真实 Verilog 代码探测出来的：

| 手法 | 结果 |
|---|---|
| `$system("...")` 执行系统命令 | **❌ 被 iverilog 禁用** —— 不能直接 RCE |
| `$fopen("/tmp/x.txt","w")` 写文件 | **⚠ 成功**（实测写出了 `PWNED VIA FOPEN`） |
| `$dumpfile("/tmp/y.txt")` | **⚠ 成功** |
| `$readmemh("/etc/hostname")` | 受限（只认十六进制格式，遇到普通文本就报错） |
| 死循环仿真 | **✅ 被 15 秒超时掐断** |

**结论**：

> **拿到口令的人，可以在服务器上"以运行服务的那个用户身份"读写文件。**

**所以**：
- ✅ 给**杜老师**一个人用 → **可以接受**
- ⚠️ 给**一个班**用 → 不建议（有人手滑或好奇就能搞出麻烦）
- ❌ **绝对不要**在存有敏感数据的服务器上开

**想彻底封死这条路**，只能把 EDA 工具链关进容器/沙箱、用专用低权限账号跑、配资源限额 ——
那是另一个工程，不是加几行代码的事。

## 五、还有一个"半个"问题没修

**Verilog 代码仍能在工程目录内写任何文件。**
`$fopen("../../x")` 这种相对路径逃逸，我用文本规则**挡不干净**（模型能构造出各种绕过写法）。

**为什么没继续修**：真正的隔离要靠操作系统（chroot / 容器 / 低权限账号），
在应用层做文本过滤是"打地鼠"，会给人虚假的安全感。
**我把风险说清楚，比做一个不可靠的过滤更负责任。**

---

## 六、顺带解决的一个老问题

**"连接工作台失败"不会再出现了。**

原因：那个问题来自 `start.bat` 每次启动时**端口漂移**
（旧服务占着 8787 没退 → 新服务跑到 8788 → 你手上的旧标签连不上 8787）。

现在做了两件事：
1. `server.py` 启动前先探测那个端口上是不是**已经在跑工作台**，是的话**直接复用**，不再起第二个
2. 报错页面会打印**当前地址**并说明"服务可能换了端口，用新地址重开"

部署到网上之后更不会有这个问题 —— **网址是固定的**。

## 七、一句话总结

| 问题 | 答案 |
|---|---|
| **能部署到公网吗？** | **能** —— 双击 `start-public.bat`，40 秒后拿到公网链接 |
| **要买服务器/注册账号吗？** | **不要** —— 用 Cloudflare 免费快速隧道，实测跑通 |
| 别人能正常使用吗？ | **能** —— 把带 token 的链接发给他，点开就能用 |
| 他能选自己要测的文件吗？ | **能** —— 三种方式：工程列表 / 拖拽文件 / 弹窗选文件夹 |
| 安全吗？ | **给一两个人用安全；给一群人用不安全**。残余风险见第四节 |
| 会读到我的私人文件吗？ | **工程目录围栏挡住了整盘浏览**；但访问者若有恶意，仍能借 EDA 工具读写文件 |
| 网址会变吗？ | **公网地址每次重启都变**，要重新发。局域网/本机地址不变 |
