脚本不认识你的工程，它只读工程目录里的 project.json。 下面三个工程都用同一个校验器跑了一遍。

python project_config.py <工程目录>

配置写对了，校验通过

通过

project.json
{
  "version": 1,
  "name": "4bit-counter",
  "top": "counter",

工程 B · 文件名打错了

写错一个字，校验器把你拦住并告诉你错在哪

未通过
工程目录结构
project.json
adder.v
tb_adder.v
project.json
{
  "name": "adder-test",
  "dut": "adder.v",
  "tb": "tb_addr.v",
  "vcd": "adder.vcd",
  "timeout": "240"
}

tb 写成了 tb_addr.v（少了个 e），而且漏了 top，timeout 写成了字符串。

校验器输出
拦下
缺少必填字段 "top"：综合的顶层模块名，对应 yosys 的 synth -top <top>。必须是 Verilog 里 module 后面的名字，不是文件名。
→ 在 project.json 里加上 "top": ...
拦下
"tb" 指向的文件不存在：tb_addr.v（完整路径 C:\Users\jinnidai2008\AppData\Local\Temp\tmpwe3mm25y\tb_addr.v）
→ 工程目录里现有的 .v 文件：adder.v、tb_adder.v
拦下
"timeout" 应为整数，实际是字符串（'240'）。
→ 每条 EDA 命令的超时（秒）。大工程综合慢就调大。
